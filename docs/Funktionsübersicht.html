Funktionsübersicht: Statistik IV

Diese Seite bietet eine kompakte Übersicht der wichtigsten R-Funktionen, die Sie in der Vorlesung und den Übungen verwenden. Die Funktionen sind nach Workflow-Schritten geordnet.

Projektstruktur & Pfade

here Paket

Das here-Paket ermöglicht reproduzierbare relative Pfade, die unabhängig vom Arbeitssystem funktionieren.

Funktion Beschreibung Beispiel
here() Gibt den Projektordner zurück here()
here("ordner", "datei.csv") Baut einen relativen Pfad here("daten", "rohdaten.csv")

Basis R — Dateioperationen

Funktion Beschreibung Beispiel

file.copy(from, to) Kopiert eine Datei file.copy("quelle.csv", "ziel.csv")
dir.create(path) Erstellt einen neuen Ordner dir.create(here("output"))

Datenvisualisierung (ggplot2)

Eine ggplot-Grafik wächst in Schichten: Daten → Mapping (aes) → Geom → Beschriftung → Theme. Schichten werden mit + verknüpft. Für die Funktionen zur Datenaufbereitung vor dem Plotten (pivot_longer(), filter(), mutate() etc.) siehe die Sektionen Daten Aufbereiten und Tidy Data weiter oben.

Grundlagen: Schichten eines Plots

Funktion Beschreibung Beispiel
ggplot(data, aes(...)) Initialisiert einen Plot und legt Daten + Aesthetics fest ggplot(daten, aes(x = gruppe, y = wm_score_t1))
aes(...) Bildet Variablen auf visuelle Eigenschaften ab (x, y, color, fill, shape) aes(x = gruppe, fill = geschlecht)
labs(...) Titel, Achsenbeschriftung, Legende, Caption Siehe unten

Merkregel: Variablen-abhängige Aesthetics gehören innerhalb aes(); feste Werte (z. B. fill = "steelblue") ausserhalb.

# Aussagekräftige Beschriftung statt Variablennamen
plot + labs(
  title   = "WM-Score nach Versuchsgruppe",
  x       = "Versuchsgruppe",
  y       = "Working-Memory-Score (Punkte)",
  fill    = "Gruppe",
  caption = "Daten: WM-Studie FS2026"
)

Geome — welche Form für welche Daten?

Funktion Geeignet für Zeigt
geom_histogram() 1 metrische Variable Häufigkeiten pro Bin
geom_density() 1 metrische Variable Geglättete Verteilung
geom_boxplot() 1 kategoriale × 1 metrische Median, Quartile, Ausreisser
geom_jitter() 1 kategoriale × 1 metrische Jede Einzelbeobachtung
geom_point() 2 metrische Variablen Streudiagramm
geom_bar() 1 kategoriale Variable Zählt Fälle pro Kategorie
geom_col() 1 kategoriale × 1 metrische Balkenhöhe aus den Daten (z. B. Mittelwerte)

Entscheidungsfrage: Wie viele Variablen mit welchem Skalenniveau? → Wähle das passende Geom. Verteilung zeigen (boxplot/jitter) ist meist informativer als ein Balken mit Mittelwert.

Zusammenfassung als eigene Schicht

Funktion Beschreibung Typische Argumente
stat_summary() Aggregiert Daten pro Gruppe und zeichnet das Ergebnis fun = mean, fun.data = mean_cl_normal, geom = "pointrange"

Mit fun.data = mean_cl_normal zeichnet stat_summary() Mittelwert + 95%-Konfidenzintervall. Das CI zeigt die Präzision der Mittelwertsschätzung, nicht die Streuung der Einzelwerte.

# Kombinierter Plot: Kennwerte + Rohdaten + Schätzung mit Unsicherheit
ggplot(daten, aes(x = gruppe, y = wm_score_t1)) +
  geom_boxplot(width = 0.15, position = position_nudge(x = -0.2)) +
  geom_jitter(width = 0.08, alpha = 0.5) +
  stat_summary(fun.data = mean_cl_normal, geom = "pointrange",
               color = "red", position = position_nudge(x = 0.2))

Gruppenvergleiche & ANOVA

Die ANOVA prüft, wie viel der Streuung in einer metrischen Variable durch Gruppenzugehörigkeit erklärt wird. Der Workflow folgt drei Schritten: Modell anpassen → Annahmen prüfen → Post-hoc-Vergleiche (wenn der Gesamttest signifikant ist und mehr als zwei Gruppen vorliegen).

afex Paket — ANOVA-Modell anpassen

Funktion Beschreibung Beispiel
aov_ez(id, dv, between, data) ANOVA mit automatischer Berechnung von Effektgrössen aov_ez(id = "id", dv = "wm_score_t2", between = "gruppe", data = wm_daten)
print(modell) Ergebnistabelle mit df, MSE, F, ges (generalisiertes η²) und p print(modell)
nice(modell, es = "pes") Formatierte Tabelle, optional mit partial η² (pes) statt ges nice(modell, es = "pes")

Argumente von aov_ez(): id = Spaltenname der Personen-ID, dv = abhängige Variable, between = Zwischensubjektfaktor(en), within = Innersubjektfaktor(en) für Messwiederholungen. Bei einfaktoriellen Between-Designs entspricht ges dem klassischen η² aus Statistik II.

performance Paket — Annahmen prüfen

Funktion Beschreibung Beispiel
check_model(modell, check = ...) Diagnostik-Panels als Grafik check_model(modell, check = c("normality", "qq", "homogeneity"))
check_homogeneity(modell) Levene-Test auf Varianzhomogenität als Zahl check_homogeneity(modell)

Ein einziger check_model()-Aufruf liefert die wichtigsten Diagnostik-Panels: QQ-Plot (Normalverteilung der Residuen) und Homogeneity-Panel (Varianzhomogenität). Punkte nahe an der Linie im QQ-Plot und eine annähernd horizontale Linie im Homogeneity-Panel sprechen dafür, dass die Annahmen erfüllt sind.

emmeans Paket — Post-hoc-Vergleiche

Funktion Beschreibung Beispiel
emmeans(modell, ~ faktor) Schätzt Mittelwerte (Estimated Marginal Means) pro Gruppe emmeans(modell, ~ gruppe)
pairs(emm, adjust = "tukey") Paarweise Vergleiche mit Adjustierung für multiples Testen pairs(emm, adjust = "tukey")

Tukey ist Standard bei ANOVA mit mehreren Gruppen; Bonferroni ist konservativer und passt bei wenigen, gezielten Vergleichen. Der Output zeigt pro Gruppenpaar estimate (Mittelwertsdifferenz), SE, t.ratio und das adjustierte p.value.

# Kompletter ANOVA-Workflow
library(afex)
library(performance)
library(emmeans)

# 1. Modell anpassen
modell <- aov_ez(id = "id", dv = "wm_score_t2",
                 between = "gruppe", data = wm_daten)
print(modell)

# 2. Annahmen prüfen
check_model(modell, check = c("normality", "qq", "homogeneity"))
check_homogeneity(modell)

# 3. Post-hoc-Vergleiche
emm <- emmeans(modell, ~ gruppe)
pairs(emm, adjust = "tukey")

Lineare Regression & Modellvergleich

Die lineare Regression sagt eine metrische Zielvariable aus einem oder mehreren Prädiktoren vorher (y = b₀ + b₁·x + e). ANOVA und Regression sind Spezialfälle desselben linearen Modells — die Diagnostik-Funktionen sind deshalb identisch.

Basis R — Modell anpassen

Funktion Beschreibung Beispiel
lm(y ~ x, data) Passt ein lineares Modell an (einfache Regression) lm(wm_score_t2 ~ sleep_hours_t2, data = wm_daten)
summary(modell) Koeffizienten, Standardfehler, t-Tests, R², F-Statistik summary(modell)
confint(modell) 95%-Konfidenzintervalle für die Koeffizienten confint(modell)

Interpretation der Koeffizienten: Der Intercept (b₀) ist der vorhergesagte y-Wert bei x = 0. Der Steigungskoeffizient (b₁) ist die erwartete Veränderung in y pro Einheit x. Pr(>|t|) testet, ob der Koeffizient signifikant von 0 verschieden ist.

Multiple Regression & Modellvergleich

Funktion Beschreibung Beispiel
lm(y ~ x1 + x2, data) Multiple Regression mit mehreren Prädiktoren lm(wm_score_t2 ~ sleep_hours_t2 + wm_score_t1, data = wm_daten)
anova(modell1, modell2) F-Test für geschachtelten Modellvergleich (Varianz-Zuwachs) anova(modell1, modell2)

Voraussetzung für anova(): Beide Modelle müssen auf demselben N basieren — fehlende Werte dürfen nicht zwischen Modellen variieren. Lösung: vor der Modellierung mit filter(complete.cases(...)) einen vollständigen Datensatz erzeugen.

# Identische Fallzahl für alle Modelle sicherstellen
wm_komplett <- wm_daten |>
  filter(complete.cases(wm_score_t2, wm_score_t1, sleep_hours_t2))

modell1 <- lm(wm_score_t2 ~ sleep_hours_t2, data = wm_komplett)
modell2 <- lm(wm_score_t2 ~ sleep_hours_t2 + wm_score_t1, data = wm_komplett)

# Lohnt sich der zusätzliche Prädiktor?
anova(modell1, modell2)

Hinweis zu R²: R² steigt mechanisch mit jedem zusätzlichen Prädiktor. Der F-Test in anova() prüft, ob der Zuwachs grösser ist als zufällig zu erwarten.

Residualdiagnostik

Funktion Beschreibung Beispiel
plot(modell) Vier Diagnostik-Plots: Residuals vs. Fitted, QQ, Scale-Location, Leverage plot(modell)
check_model(modell, check = ...) Diagnostik-Panels via performance (gleiche Funktion wie bei ANOVA) check_model(modell, check = c("qq", "normality", "linearity", "homogeneity"))

Die wichtigsten Diagnose-Panels: Residuals vs. Fitted prüft Linearität (sichtbarer Trend = Verletzung), Scale-Location prüft Homoskedastizität (Fächer-Form = Verletzung), QQ-Plot prüft Normalverteilung der Residuen (Abweichung von der Linie = Verletzung).
